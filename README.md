# Global Computer Portfolio

A custom, installable WordPress theme for Saidul Islam's personal portfolio and the separate **Global Computer & Technology** business profile.

## Deliverables

- Theme source: `global-computer-portfolio/`
- WordPress install ZIP: `global-computer-portfolio.zip`

## Install

In WordPress Admin, go to **Appearance → Themes → Add New → Upload Theme**, choose `global-computer-portfolio.zip`, install, and activate. The theme creates `/global-computer-technology/` on activation if a page with that slug does not already exist.

Update content and upload the real shop logo at **Appearance → Customize → Business Profile**. The legal/license fields are intentionally blank because the supplied brief did not include a license number or address; enter the real details before publishing them.
